# Aula 02 de Formação de Programadores

### tipos de sistemas de informação;

 1.Sistemas Transacionais (OLTP)
Processam transações em tempo real
Exemplos: Sistemas bancários, e-commerce, PDV (ponto de venda)
Foco: Velocidade e integridade dos dados

2. Sistemas de Apoio à Decisão (DSS)
Auxiliam executivos e gerentes em tomadas de decisão
Exemplos: Análise de vendas, previsões de demanda
Foco: Análise e relatórios

3. Sistemas de Informações Gerenciais (SIG)
Fornecem informações para gestão operacional
Exemplos: Relatórios de desempenho, controle de estoques
Foco: Informações consolidadas

4. Sistemas de Suporte Executivo (ESS)
Voltados para nível estratégico
Exemplos: Dashboards, indicadores-chave de desempenho (KPIs)
Foco: Visão estratégica

5. Sistemas de Processamento em Lote (Batch)
Processam grandes volumes de dados periodicamente
Exemplos: Folha de pagamento, processamento de faturas
Foco: Eficiência em grandes volumes

6. Sistemas em Tempo Real
Processam dados imediatamente conforme ocorrem
Exemplos: Sistemas de controle industrial, monitoramento
Foco: Resposta imediata

7. Sistemas ERP (Planejamento de Recursos Empresariais)
Integram todos os processos da empresa
Exemplos: SAP, Oracle, Microsoft Dynamics
Foco: Integração total

8. Sistemas CRM (Gestão de Relacionamento com o Cliente)
Gerenciam relacionamento com clientes
Exemplos: Salesforce, HubSpot
Foco: Satisfação do cliente

9. Sistemas de Inteligência de Negócios (BI)
Transformam dados em inteligência competitiva
Exemplos: Power BI, Tableau, Looker
Foco: Análise e visualização

10. Sistemas Colaborativos
Facilitam comunicação entre equipes
Exemplos: Slack, Microsoft Teams, Jira
Foco: Produtividade em grupo
